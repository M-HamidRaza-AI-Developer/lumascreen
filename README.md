## 📁 Project Files

```
lumascreen/
├── .streamlit/            ← Streamlit configuration folder
├── __pycache__/           ← Python auto-generated cache (ignore/exclude from git)
├── README.md              ← This file
├── app.py                 ← Main Streamlit app entry point
├── generate_index.py      ← Master Python script to generate index.html
├── index.html             ← Generated frontend page (with offline fallback support)
├── requirements.txt       ← Python dependencies
├── scripts.py             ← All JavaScript (SPA routing, auth, multi-language, modal)
├── styles.py              ← All CSS styles + SVG logo assets
├── tmdb_helpers.py        ← TMDB API calls + HTML card builders (Trending, Upcoming, etc.)
└── viktor.config.toml     ← Project configuration file
```

## 🚀 How to Run Locally in VS Code

### Step 1 — Clone or place all files in one folder

Make sure all project files are together in your `lumascreen/` folder as shown above.

### Step 2 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 3 — Set your TMDB API Key (optional)

Get a free API key at: [https://www.themoviedb.org/settings/api](https://www.themoviedb.org/settings/api)

**Windows (PowerShell):**
```powershell
$env:TMDB_API_KEY = "your_api_key_here"
```

**macOS / Linux:**
```bash
export TMDB_API_KEY="your_api_key_here"
```

### Step 4 — Generate the frontend

```bash
python generate_index.py
```

### Step 5 — Run the app

**Option A — Streamlit app:**
```bash
streamlit run app.py
```

**Option B — Static local server:**
```bash
python -m http.server 8000
```
